## Instructions For Set Up:
1. Download repo as local repository. Make sure you are on the master branch to complete the next steps.
2. Run GenerateProjects.bat file (found at OrionEngine/OrionEngine/GenerateProjects.bat).
3. Open generated OrionEngine.slnx (found in generated OrionEngine/OrionEngine/build directory) and run it in Visual Studio.
4. Right click Editor in the Solution Explorer and select Set as Startup Project.
5. Run without debugging. (shortcut: CTRL+F5)
